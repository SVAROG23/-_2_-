Выводы по каждому пункту задания:

1. Чтение данных
С помощью pd.read_excel() загружен файл Coffee Shop Sales.xlsx (лист Transactions). Выведены первые 5 строк (head()), информация о типах данных (info()) и базовая статистика (describe()). Данные успешно считаны. Всего загружено 149116 строк и 11 столбцов. Пропущенных значений нет.

2. Фильтрация
Выполнена фильтрация записей по двум условиям: цена unit_price больше 3.0, а категория product_category равна Coffee. 
В результате фильтрации осталось 22468 строк. Выведены первые 5 подходящих записей.

3. Группировка и агрегация
Данные сгруппированы по категории продукта (product_category). По каждой категории рассчитаны: количество транзакций, средняя цена, суммарное количество товаров и максимальная цена. Таблица отсортирована по средней цене по убыванию. 
Самая высокая средняя цена (21.01) оказалась у категории Coffee Beans.

4. Новый столбец
С помощью numpy.where() создан новый признак price_level. Средняя цена по всей таблице составила 3.38. Если цена товара превышает это значение, ставится метка «выше среднего», в противном случае — «ниже или равно».

5. Использование NumPy
Столбец unit_price конвертирован в массив NumPy (ndarray). Рассчитаны основные статистические показатели: 
- Среднее: 3.38
- Стандартное отклонение: 2.66
- Максимум: 45.00
- Минимум: 0.80
Выполнена мин-макс нормализация, выведены первые 5 нормализованных значений.

6. Сохранение
Обработанный датафрейм (со всеми исходными строками и новым столбцом price_level) сохранён в файл processed_coffee.csv. При сохранении использована кодировка utf-8-sig и разделитель `;` для корректного отображения кириллицы и разбивки по столбцам в русской версии Excel.
